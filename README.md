# Telco Customer Churn Analysis

## 1. Introduction

This project focuses on preprocessing and exploring the Telco Customer Churn dataset using Python. The aim is to understand customer characteristics and identify patterns related to customer churn.

## 2. Objectives

- Load and inspect the dataset.
- Convert the Churn attribute from Yes/No to 1/0.
- Check data types and handle missing values.
- Explore demographic characteristics in relation to churn.
- Analyze phone services and customer payment preferences in relation to churn.
- Interpret the results of each analysis.

## 3. Tools and Technologies

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## 4. Dataset

The dataset is the Telco Customer Churn dataset available on Kaggle.

Dataset source: [https://www.kaggle.com/datasets/blastchar/telco-customer-churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)

## 5. Project Structure

- `telco_churn_analysis.ipynb` — notebook containing the Python code, outputs, charts, and interpretations.
- `WA_Fn-UseC_-Telco-Customer-Churn.csv` — dataset used for the analysis, if included in the repository.

## 6. Expected Results

The analysis will help explore how demographic characteristics, phone services, contract types, paperless billing, and payment methods are associated with customer churn.
